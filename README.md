# 日本産クモ類 生息候補地データベース

公開サイト：https://spider-habitat-atlas.pages.dev/ （2026-10-08初回公開）

生息環境の記述・県別記録・土地被覆から調査候補地を探し、同じ条件で面積を比較する非商用の研究サイト。候補地は生息確認・出現確率・希少性を示さない。2026年4月26日の東京蜘蛛談話会の発表を出発点とする。

## 現在の機能

分類はJapan Spider Catalog ver. 2.0.7（2026-10-08取得）の1,741分類群、生息環境登録は796分類群。2026-10-09の条件修正後は、全178環境のうち50環境を計算、95環境の計算・配布を保留、33環境をその他の未評価とする。保留中の環境も名称で検索できる。

土地被覆と、水域・人工構造物・林縁・水田までの100m・250m・500mの距離、植生図の区分を組み合わせる。標高・海岸線距離・河川距離は計算・配布から除外する。それらの条件が必要な環境全体も計算対象外にし、一般の森林・草地や水辺で代用しない。元の研究データは変更せず保持する。

生息環境の複数選択、土地被覆の個別オン・オフ、種・属での比較、県別・環境別CSV、表示範囲のGeoJSONに対応。同じ条件を地図・面積・出力へ適用する。比較上限は最多属の収録種数で、現在はCybaeusの93種。分布記録は本土・島・地域詳細不明を区別し、県境をまたぐ区画も所属県ごとに集計する。

[計算方法](docs/spatial-model.md)・[全環境の対応一覧](docs/habitat-condition-review.md)・[素材と利用条件](docs/sources.md)・[学名対応](docs/taxonomy-review.md)。

## 実行と検証

Node.js 22以降を使用。解析の再計算にはPythonとnumpy・scipy・rasterio・geopandas・pyogrio・shapelyが必要。原本はリポジトリ外かGit管理外に置く。

```sh
npm run dev
npm test
npm run check
python -m unittest discover -s tests -p 'test_*.py'
```

プレビューは http://127.0.0.1:5187 。アプリは `site/` 内の公開ファイル、配信データは `local/public-spatial/`、Web用資料画像は `local/public-presentation/` から提供する。配信データ・資料画像にはファイル名の許可リストがあり、アプリのルート外や隠しファイルは読めない。`site/` に私的なファイルは置かない。指定したルート内に `data/spatial/`・`slides/` がある場合はそれらを優先するため、完成した公開用フォルダも同じサーバーで確認できる。`npm run build` は整合性検査であり、公開用フォルダの作成は次項の別コマンドで行う。

通常のプレビューではCodex注釈用のスタイルを許可する。`npm run dev -- --strict-csp` では公開時と同じCSPを使う。スクリプトや通信先、Host・Origin・パスの制限は維持する。

## 公開用データ

入力の構築方法は[入力契約](docs/data-contract.md)と[計算方法](docs/spatial-model.md)を参照。研究計算が揃った後、公開専用の新規フォルダを作る。

```sh
node scripts/prepare-public-spatial.mjs
node scripts/check-public-spatial.mjs
python scripts/audit_habitat_rules.py
node scripts/build-public-site.mjs
node scripts/check-public-site.mjs
```

標高・海岸線距離・河川距離の軸を合算して除き、残る条件の画素数と面積を保つ。全2,260タイル・6,068,603県別区画を原本からの射影と照合する。研究用の環境規則を更新する場合だけ `python scripts/audit_habitat_rules.py --research --refresh` を使い、その後に公開用データと対応一覧を再生成する。

公開対象は `output/public-site/` のみ。検証済みマニフェストが参照するデータと、ハッシュを記録した資料画像だけを収録する。原GIS・研究CSV・PPTX・観察者情報・申請控えは含めない。データがない場合はエラーを表示し、別モデルへ自動切替しない。

## 無料公開とプライバシー

Cloudflare Pagesの無料のpages.dev URLで公開済み。Functions・DB・有料ストレージ・独自ドメインは使わない。[更新手順](docs/release-checklist.md)に従い、確認済みフォルダだけを配信する。[初回の配信記録・公開後の作業](docs/post-release.md)に本番検証と残る作業をまとめた。

標高の準備版では、種・条件別の集計と広域図を必要時に取得する。狭い範囲は県別ファイル、拡大時は必要な250mタイルを使い、説明ページは計算用ファイルを読み込まない。取得先は同じ配信元で、選択に対応するファイル名とIPアドレスが配信元へ送られる。検索文字列や生成したCSV・GeoJSONのアップロードはしない。

初期表示の背景は「背景なし」。利用者が選んだときだけ地理院タイルを取得し、検索条件を参照元URLとして送信しない。独自のアクセス解析、Cookieによる追跡、ログイン、閲覧時のAI APIはない。

発表資料20ページとメールアドレス・ResearchGateリンクは維持。自己作成・フリー素材のアイコンも維持する。Web用コピーでは発表者氏名を除き、利用条件を確認中の図は保留。引用文献の著者名は出典として残す。

研究用の本リポジトリは非公開。[コードと説明資料の公開リポジトリ](https://github.com/keshikata/spider-habitat-database)へは、配信データ・資料画像・ローカル監査資料を含めず同期する。回帰確認の詳細は[検証記録](docs/validation.md)に残す。

SNS共有用のOGP・Xカードを設定。[共有表示と更新時の確認](docs/sharing.md)に画像・タグ・検査の手順を記載する。共有画像の編集ソースは `design/social-card/` に保持し、フォントと編集ファイルはサイトへ配信しない。
