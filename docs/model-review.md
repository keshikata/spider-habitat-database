# 既存モデルのレビュー

確認日: 2026-10-08。R Ver.5、解析README、発表スライド、環境情報CSV、Geo-Habitat-Finderの環境集計、Japan Spider Catalogの分類エクスポートを確認した。

## このサイトで答える問い

種について記載された生息環境と、利用可能な環境レイヤが対応する場所はどこか。同じ環境データ・計算条件のもとで、その面積が種間でどう異なるか。実際の占有、生息密度、絶滅リスクの推定はこの出力から直接行わない。

## 修正が必要な点

1. **土地被覆と微環境を分ける。** 旧対応表には海岸・河原・川辺を水域へ対応させた項目がある。陸上の岸辺と水面は同じではない。水際への距離や隣接条件を評価しないモデルでは、その条件を判定保留にする。
2. **面積と記録強度を分ける。** Ver.5は県の記録強度と適性を統合し、種ごとの最大値で0–1へ正規化している。この値を同じ閾値で切った面積は、種間で同じ生態学的意味を持たない。面積比較は環境条件への二値適合から算出し、対象地域・分布制約・欠損処理を揃える。
3. **NoDataは不適合と区別する。** Ver.5の標高欠損はスコア0、DEMが作れない場合は標高条件全体の無効化となる。どちらも実行条件によって意味が変わる。未知の面積と判定できた面積を別に報告する。
4. **地図の平滑化を面積へ使わない。** 元コードは表示時にbilinear再投影、平滑化、拡大を行う。見た目を整えた画像から面積を数えず、元の格子・分類で集計する。
5. **評価対象を一定にする。** Ver.5のCVは条件不足時に標高なし・OR・マスクなしへ変更する。本番の幾何平均とCVの積も同一ではない。別条件の結果を単一モデルの精度としてまとめない。県レベルの記録による評価で250mセルの精度は検証できない。
6. **最頻カテゴリだけで面積を数えない。** 250mへの最頻値集約は小さな草地や水際を失う。公開用の粗いメッシュには細かい元画素の該当面積を集計し、粗いメッシュ全面が適地とは表現しない。
7. **年の意味を保存する。** 文献刊行年と採集年は別。旧CSVの`year`を検証せず現在の在不在や記録の新しさとして解釈しない。

## Jevから採用する考え方

[TypeSafeの紹介記事](https://typesafe.ai/blog/introducing-system-one-models-and-jev)は、あらかじめ定義した型の判断と、その確率を返すモデルを説明している。出力形式の保証を、生態学的な正しさの保証と解釈しない。

今回採用するのは、自由文から無制約に「適地」を作るのでなく、有限の土地被覆カテゴリ、判定保留、追加条件へ変換する設計。Web実行時の外部AI呼び出しは必要としない。モデル名・規則版・入力ハッシュを固定すれば再計算できる。将来の学習モデル導入には、専門家の独立した正解付与と、同じ表現が学習・評価へ混入しない分割が必要。

## 面積の意味

`候補面積 = Σ（土地被覆が許容カテゴリに入る元画素の地表面積）`。複数カテゴリは集合の和とし、同じ画素は二重計上しない。緯度経度格子の画素を一律100m²とは扱わない。

全国の環境候補と、記録のある県内の環境候補は別の対象範囲。未記録県は不在県ではなく、記録県内の全域で生息するという意味でもない。面積の小ささを希少性の順位へ置き換えない。分類群による微環境の表現可能性の差も併記する。
