# 公開前の最終確認

2026-10-08。personal-dev-kitの品質・レスポンシブ・セキュリティ・リリース基準を参照し、公開専用フォルダを検証した。本書は公開前の検証記録。後に公開日だけを追記して同日公開し、[本番での確認と公開後の作業](post-release.md)へ結果を記録した。

## 今回の改善

- 公開ファイルを名前の許可リストでコピーする。完成したフォルダでも、余分なファイル・欠落・シンボリックリンク・私的なPC内パス・秘密鍵・除外対象の氏名を検査する。
- すべての配信データと確認済み資料画像のサイズ・SHA-256を照合する。画像の検証情報が欠けている場合も検査を失敗させる。圧縮データの展開量をビルド時にも制限する。
- ハッシュ付きの地図ファイルを長期キャッシュし、更新されるマニフェスト・検索情報を再検証する。重複するCache-Control指定を解消した。独立した初期データは並行して読み込む。
- 閲覧開始時にIPアドレスとアクセス先URLが配信元へ送られることを説明に追加した。共有URL内の条件もそのURLに含まれる。独自の追跡・ログインはなく、画面内の計算・保存はブラウザー内で行う。
- 縦スクロールの有無で画面が横へずれるのを抑制した。初期背景なし、青いフォーカス、共通のボタン・補足表示を維持した。

## 軽量化の測定範囲

初期の検索・集計・地域データは圧縮後約6.31MB（地図や資料画像を除く）。地図は必要な県・範囲だけ取得する。全333.9MBを初期表示時に一括取得する構成ではない。

このPCのNode.jsで93種を集計した時間は初回186.3ms、同条件の再計算52.0ms、記録範囲に限定した集計94.6ms。これは計算処理の測定で、スマートフォンの描画時間・回線速度・LCP/INPの実測値ではない。再訪時の通信削減はキャッシュ設定により対応し、実際のCDN応答は配信後に確認する。

## 利用条件と公開時に残る確認

[素材別の利用条件](sources.md)に基づき、2026-10-09の修正後は50環境を計算、95環境の計算・配布を保留、33環境をその他の未評価とする。保留中の環境も名称検索は可能。標高・海岸線距離・河川距離は公開数値から除き、これらの限定が必要な環境全体も計算から除外する。DEM由来の資料図の保留、原本PPTX、自己作成・フリー素材のアイコン、公開を希望するメール・プロフィールは保持する。

公開候補は[Cloudflare Pages Freeのファイル数・サイズ制限](https://developers.cloudflare.com/pages/platform/limits/)以内。GitHubへ同期するのはコード・説明資料であり、配信データ・資料画像・私的な監査記録は含めない。

公開時には[手順](release-checklist.md)に沿って、検証済みフォルダのアップロード、実際の公開日の記載、HTTPS・CSP・キャッシュ・ダウンロードの確認を行う。実機のSafari/iOS・Android、低速回線での性能、支援技術による網羅的な検証、現地記録による生態学的な精度検証は今回の結果に含めない。
