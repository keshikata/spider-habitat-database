# 日本産クモ類 生息候補地データベース

生息環境の記述・県別記録・土地被覆を組み合わせ、クモの調査候補地を検索し、種ごとの候補面積と環境内訳を比較する静的Webサイトのコードです。

2026年4月26日の東京蜘蛛談話会例会で発表した「クモの生息地を推定する簡易モデルの試案」をもとにしています。現在のWeb版は、土地被覆と水域・人工構造物・海岸線・林縁・水田・河川中心線への距離、植生図を組み合わせ、約250m単位で候補を表示します。[全178環境の条件](docs/habitat-condition-review.md)に計算可能な条件・近似・不足データを記録しています。標高による絞り込みは未実装で、将来の対応を予定しています。気温・微環境は評価していません。候補面積は実際の生息面積や出現確率ではありません。

## このリポジトリに含むもの

HTML/CSS/JavaScript、データ変換・検証スクリプト、計算のテスト、方法・出典の説明資料を公開しています。研究用CSV、配信データ、GIS、スライド、記録者情報、ローカル監査資料は含みません。元の研究用リポジトリは別に管理しています。

## 開発とテスト

Node.js 22以降とPython 3.10以降を使用します。通常のテストには追加パッケージは不要です。距離・植生・地域区分の再計算には、別途 `numpy`・`scipy`・`rasterio`・`geopandas`・`pyogrio`・`shapely` を使用します。

```sh
npm test
python -m unittest discover -s tests -p 'test_*.py'
```

研究用の学名対応表を必要とするPythonの2テストは、データ未配置の場合だけスキップされます。距離変換の3テストは分析用依存がない場合にスキップされます。

Webサイトを実行するには、利用権限のある入力から配信データを作成してください。[入力契約](docs/data-contract.md)を参照。

```sh
python scripts/sync_jsc.py --date 2026-10-08 --out local/jsc-live
python scripts/build_data.py --jsc local/jsc-live --habitat /path/to/habitat --environment /path/to/trial-data
python scripts/pack_maps.py
npm run check
npm run dev
```

取得日には実際の日付を指定し、分類参照日や更新履歴も更新します。学名対応表は入力契約に従って配置します。プレビューは http://127.0.0.1:5187 。一般公開の配信対象は `site/` のみです。ローカルプレビューでは、別途作成した距離・植生条件のデータと発表資料の許可ファイルも専用URLから読み込めます。研究用入力や申請記録は配信しません。

ローカルプレビューでは、Codexの注釈が挿入するスタイル要素を許可します。スクリプトや通信先の制限は維持し、Cloudflareへ配信する `site/_headers` は変更しません。公開時と同じCSPを確認する場合は `npm run dev -- --strict-csp` を使ってください。このモードではCodexの注釈表示が制限されます。

## 表示と計算

- 地図は必要な地域の広域データを取得し、拡大時は表示範囲の詳細タイルを読み込みます。
- 面積は元の画素数を緯度に応じた面積に換算し、画面の拡大倍率とは独立して集計します。
- 同じ画素を二重に数えず、未評価とゼロを区別します。
- 生息環境の名称と検索条件を並べ、複数選択できます。環境から種を絞り込み、その選択を地図・面積比較・データ出力に反映します。
- 比較する種は未選択から開始し、属による絞り込みと追加に対応します。上限は収録種数が最多の属から求め、現在はCybaeusの93種です。
- JSCの分布記録を本土部・離島・地域詳細不明に分け、記録のある本土・島に候補範囲を限定します。島の区分は約250m単位の近似で、対応できない島は除外して表示します。
- 県境をまたぐ区画も、約10mの画素を所属県ごとに分けて集計します。
- CSVは環境別・県別に出力し、選択した環境名・環境ID・出典と計算条件を付けます。
- 約10mの元画素から距離と植生区分を求め、約250mへ集計します。距離は100m・250m・500mを切り替えます。
- 地図表示範囲はGeoJSONとして出力でき、選択環境と距離・植生条件も含めます。解析データはこのリポジトリに含みません。
- 閲覧時のAI API、ログイン、独自のアクセス解析、解析用バックエンドはありません。背景地図は初期状態では表示せず、選択したときだけ地理院タイルを取得します。検索条件を参照元URLとして送らない設定です。

## 配信と回帰確認

距離・植生のデータを生成済みの環境では、次のコマンドで集計を圧縮し、広域地図を県・地域区分ごとに分割できます。計算値は変更せず、検査で元の値との完全一致とSHA-256を確認します。解析データはこのリポジトリに含みません。

```sh
node scripts/pack-spatial-delivery.mjs
node scripts/check-delivery.mjs
```

2026-10-08のローカル検証では、初期集計と配信マニフェストが約36MBとなり、旧集計・地域区分・全国広域の圧縮合計約109MBから約67%減りました。対象地域の地図は追加取得します。背景地図・詳細タイル・HTML・ライブラリはこの比較に含みません。キャッシュは展開後のデータサイズを基準に上限を設け、不要な読込は中断します。

JavaScript24件とPython20件のテスト、元データとの照合に合格。320・390・768・1280px幅、最大93種の比較、CSV・GeoJSON出力、地図の拡大表示とキーボード操作を確認しています。ローカルHTTP配信のHost・Origin・パス境界、圧縮上限とキャンセルもテスト対象です。公開後のHTTPS・配信ヘッダーの確認はデプロイ時に実施します。
