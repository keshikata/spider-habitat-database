# 入力データと公開データの境界

ブラウザへ配信するデータと、ローカルで処理する研究資料を分ける。研究資料は公開リポジトリに含めない。

## 入力

`scripts/sync_jsc.py` はJapan Spider Catalogの公開サイトから、分類・分布記録・更新履歴の3ファイルをローカルへ取得する。辞書圧縮された表を復元し、種・亜種の分類と県別の記録件数に変換する。配信元の写真・人物・備考・座標は出力しない。

生息環境の入力CSVは `Scientific Name` と `habitat_text` の列を持つ。利用権限のある資料を用意し、元の図鑑記述をそのまま配信しない。

種の `recordAreas` は県番号をキーとし、`mainland`（本土部の記録の有無）、`islands`（島名の重複なし配列）、`unspecified`（地域詳細不明の記録の有無）を保持する。北海道・本州・四国・九州を本土部とし、不明を本土へ振り分けない。JSCの通常記録のみを使用する。現在の約250m版では、この区分と行政区域の陸地図形を対応させ、記録のある本土・島へ候補面積を限定する。対応できない島は除外し、地域詳細不明の県別記録は県全域を使う。

基本版の環境集計は9地域のJSONを入力する。`version: 3`、`grid: "third_order"`、`aggregation: "all_source_pixel_centers_by_prefecture"`。`cells` は `[第3次メッシュコード, [[県番号, 16分類の画素数]]]` の配列で、単一県の区画を対象とする。画素格子は1/12000度。分類コード0は未分類、1～15はJAXAの分類に対応する。現在の約250m版は元ラスタを再集計し、県境をまたぐ区画の画素も所属県別に保持する。異なる版・格子・分類のデータへ無検証で差し替えない。

研究資料の学名対応は `site/data/taxonomy-crosswalk.json` の `rows` に置く。各行は `sourceName`、`status`、`catalogName`、`catalogId`、`acceptedName`、`relation`、`note`、`evidence` を持つ。`status: "mapped"` の場合だけ統合し、元資料の種概念を確認する。対応が不要な新しい入力だけを使う場合は `{"rows": []}` から始められる。WSC由来の対応情報には所定の出典と利用条件を付す。

## 出力

`build_data.py` は `site/data/catalog.json` と地域JSONを作る。`pack_maps.py` は検索用の軽量データと47県の詳細地図、8×8区画をまとめた広域地図をgzipで作る。面積は県・分類別の元集計を使用し、粗視化した地図から再計算しない。

地図のmanifestは圧縮ファイル名、SHA-256、圧縮前後のサイズ、区画数、範囲を記録する。ファイル名にはハッシュの先頭12文字を含む。ブラウザはサイズ上限とハッシュを検証し、必要な県だけを取得する。

## 再現性の確認

同じ入力とコード版で再構築し、`npm run check` で、元の地域JSONと圧縮版の全区画・全分類の一致を調べる。分類と県別記録を更新する場合は、取得日・出典・入力ハッシュ・更新履歴も合わせて更新する。計算の一致は、モデルの生態学的な予測精度を保証するものではない。

## 土地被覆・距離・植生の約250m版

[入力・計算・出力](spatial-model.md)を参照。ラスタ・参照図形の入力は読み取り専用で、出力先は `local/spatial-reference/`。`node scripts/check-spatial.mjs` は全圧縮ファイルのハッシュ、区画の重複、県境での画素重複、広域集計の画素数、県別面積を検査する。`node scripts/check-record-geography.mjs` は本土・島別の面積と地図の一致を検査する。これらのデータを `site/` や公開リポジトリへ自動コピーしない。

環境規則は `id`（H001形式）、`label`（検索用の環境名）、`baseClasses`（基本版の対応）、`classes`（近似条件を含む対応）と、水域・人工構造物・海岸線・林縁・水田・河川中心線への距離条件、植生区分を持つ。`supported`、`proxy`、`pending`、`limitations` で計算の可否と限界を保持する。`elevation` は内部研究用に残すが、サイトの標高絞り込みは未実装。IDは入力環境語彙の並びから作るため、入力版が変われば同じ意味を指すとは限らない。共有URL・出力はデータ版とともに扱う。長い原文や出典のページ全文は含めない。

既存のラスタ集計を維持したまま記録区分・環境規則を更新する場合は `python scripts/enrich_metadata.py --jsc local/jsc-live --habitat /path/to/habitat` を使う。これは画素の距離や標高を再計算する処理ではない。
