公開中の更新を止め、直前の正常な本番版へ[Cloudflare Pagesのロールバック](https://developers.cloudflare.com/pages/configuration/rollbacks/)を行う。初回版しかない場合は修正か公開停止を判断する。許諾待ちの研究データへ置き換えない。修正後は失敗した操作と関連する回帰テストを通して再公開する。
