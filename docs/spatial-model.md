# 生息環境を約250m区画へ集計する方法

2026-10-08更新。モデル `spatial-exploration-1.3.0`、schema 5。解析データはローカル検証用で、一般配信していない。サイトは土地被覆・距離・植生図を使用する。標高による絞り込みは未実装・将来対応として選択不可にした。内部の標高研究コードと既存データは保持している。

## 入力と条件

JAXA HRLULC 2024JPN_v25.04の約10m画素と、国土数値情報の行政区域2025年版、海岸線2006年版、河川2006～2009年版、環境省の現存植生図2024を組み合わせる。GHFの入力は読み取り専用。[素材と利用条件](sources.md)を参照。

一つの環境に必要な条件はAND、複数の環境はORで結合する。同じ画素を二重に数えない。環境選択は種の一覧・比較・地図・出力に共通適用し、各種の登録環境との積集合を計算する。全解除は「環境未選択」とし、評価したゼロと区別する。

| 環境 | 条件 | 限界 |
| --- | --- | --- |
| 海岸の草地 | 草地 AND 海岸線への距離 | 内陸の水域は海岸としない。2006年以降の海岸変化は未反映。 |
| 水辺の草地 | 草地 AND 土地被覆の水域への距離 | この水域は海を含み、細い流路は欠落し得る。 |
| 林縁の草地 | 草地 AND 森林・竹林と他の既知分類の境界への距離 | 未分類との境界は林縁にしない。 |
| 水田の畦 | 草地 AND 水田への距離 | 畦の幅・形状や管理状況を識別した結果ではない。 |
| 河川敷 | 草地 AND W05河川中心線への距離 | 堤防・冠水域や河岸線ではない。幅の広い河川の岸を取りこぼし得る。 |
| 河原 | 草地・裸地・岩礁等 AND W05河川中心線への距離 | 底質を同定するものではない。 |
| 果樹園 | 畑・草地・森林等 AND 植生図の果樹園・常緑果樹園 | 土地被覆と植生図の時点・縮尺が異なる。 |
| 植林地・造林地 | 森林 AND 植生図の植林凡例 | 管理状態や現在の樹種までは判定しない。 |
| 牧草地 | 草地 AND 植生図の牧草地 | 小区画や利用変更は反映されない場合がある。 |
| ハイマツ帯 | 植生 AND 植生図のハイマツ群落 | 気候帯全体ではなく、原図に記載された群落の範囲。 |
| 薮 | 植生 AND 植生図の低木群落・落葉広葉低木群落 | 植物名に「ヤブ」を含むだけの凡例は使わない。林内の下層は識別しない。 |

W05の区間種別1～4を使用し、湖沼兼用区間5～8と不明を除く。元ファイルの無効な線形1件を除外し、来歴へ記録した。渓流・河口・湖沼を一般の河川距離で代用しない。

全178環境の照合結果は[対応一覧](habitat-condition-review.md)。14環境は指定条件を計算し、109環境は限界を表示した近似、55環境は未評価として除外する。除外環境名は画面と出力に残す。標高の限定が未実装の環境ではその旨を表示する。

## 距離と植生図

距離は100m・250m・500m以内・500m超の4帯。処理区画中央の緯度でWGS84のメートル換算を行い、500mを超える周辺画素を含めて距離変換する。線形を通過する約10m画素を起点とするため、格子幅程度の近似誤差がある。道路沿いの移動距離や厳密な水際からの距離ではない。

植生図の選択凡例を土地被覆画素の中心で判定する。GHFの地域別GeoPackageから必要な凡例を取り込み、FlatGeobufの空間索引を使う。分類の重なりは分類番号・凡例名順の固定規則で上書きする。原図を約10m格子へ変換しても原図の精度が10mになるわけではない。

`prepare_reference_layers.py` は植生図8ブロックの公式ArcGIS項目からCC BY 4.0を確認し、日付・URL・ライセンス本文を保存する。入力GeoPackageと47河川ZIP、生成FlatGeobufのサイズ・SHA256を記録する。原図形・派生データはGit管理外に置く。

## 県境と本土・離島

県境をまたぐ1km区画を除外していた旧版から変更し、行政区域ラスタによる画素の所属県で集計する。250m区画が複数県にまたがる場合は県ごとの行を保存し、全国表示時に同じ区画の候補画素と母数を合算する。地域別処理は重ならない県番号の組を担当し、同じ画素を別地域で重複計上しない。

旧収録メッシュ内の分類別画素数は各処理タイルで一致検査する。その上で県境等の画素を追加するため、旧版の総面積には増分がある。データ欠損を塗りつぶす処理ではない。

本土・島はN03の県別陸地図形とJSCの島の代表点を対応させる。各県の最大の連続陸地を本土とする（沖縄県を除く）。島の点が一つの陸地図形に入る場合だけ対応し、近接による推測をしない。未対応の島名は除外し、画面・出力へ記載する。

区画中心がその県の陸地図形にない場合、その県の陸地図形と一つだけ交わる区画を採用する。複数の陸地にまたがるものは割り当てない。県境で中心が隣県にあることだけで画素を捨てない。島境界を画素ごとに分割した処理ではなく、小島・運河・原図の分割による欠落は残り得る。

以前の区分を使う場合、本土ID・ポリゴン順序・県・外接範囲を検査して島名との対応を引き継ぐ。範囲不明の県別記録は県全域を使う。「全地域の環境だけで比較」は記録制限を外す。

## 集計形式と出力

分類組合せは疎形式で保持する。schema 5のキーは、旧schema 4に `河川距離帯 × 65536 + 植生区分 × 262144` を加える。植生区分は0（指定5分類以外）・1果樹園・2植林・3牧草地・4ハイマツ・5低木。0を植生図の不存在の証拠として使わない。

250m区画は経度1/320度・緯度1/480度。該当画素数に区画中心の緯度における楕円体上の画素面積を掛ける。広域地図は区画をまとめるが、面積表示は縮尺で変わらない。地図の割合は該当画素数／収録画素数。分類0は未分類で候補面積に含めない。

地図・面積・CSV・GeoJSONは同じ条件と地域範囲を使う。GeoJSONは経度・緯度順（CRS84）、区画・面積・割合・選択環境・6種類の距離・植生区分・未評価条件・近似の限界・出典を保持する。ポリゴン全面を生息地境界と扱わない。

## 比較の上限と処理

固定8種から、収録カタログで最大の属の種数へ変更。現行1,741種ではCybaeusの93種。環境未収録の種も属の総数に含めて上限を決め、選択肢には現在計算できる種を出す。データ更新時に自動更新する。

条件マスクは最大24組、基礎マスクは128組を保持し、集計行は数値配列へ一度だけ変換する。93種のグラフはスクロール領域で表示する。`benchmark-comparison.mjs` で最大属と93種混合の全国・記録範囲別を計測する。

2026-10-08の実データで93種の全国計算は初回826.3ms、再計算257.8ms、記録範囲593.3ms。Nodeでの計算時間で、通信・描画を含まない。実画面でも93種表示を確認した。

## 再生成と検証

```sh
python scripts/prepare_reference_layers.py --ghf /path/to/Geo-Habitat-Finder
python scripts/build_reference_spatial.py --rasters /path/to/processed/rasters --borders /path/to/public-trial/border-meshes.json --workers 4
python scripts/build_record_geography.py --out local/spatial-reference --boundaries 'zip:///path/to/N03-20250101_GML.zip!N03-20250101_prefecture.shp' --previous local/spatial-compound/geography.json.gz
python scripts/audit_habitat_rules.py --refresh
node scripts/check-spatial.mjs
node scripts/check-record-geography.mjs
node scripts/benchmark-comparison.mjs
```

`local/spatial-reference/` をループバックサーバーの許可されたファイル名で配信する。基本版と旧版も保存する。タイルの来歴はビルドコード・参照データハッシュ・凍結ラスタのサイズと更新時刻・県境一覧を含む。キャッシュした圧縮ファイルのSHA256も検査する。再生成中に入力を差し替えない。

元画素との一致、詳細・広域の画素数、県・島別面積、距離条件の単調性、県境での重複、出力条件を確認する。計算検査と、独立した観察記録による生態学的精度検証は別である。

1.3.0は2,260タイル、6,068,603県別区画、5,569,788,666画素。詳細・広域・県別面積が一致し、最大誤差は1.7882e-8 km²。県境を共有する41,016区画も検査した。圧縮した全国広域は36.4MB、地域区分は55.7MBあり、後述の配信用パックでは県ごとに分割済み。現在はループバック配信だけを行い、サイズ上限とハッシュで読み込みを検証する。

## 標高と公開状態

内部研究ではDEM10mと200m・800mの仮区分を使った計算があるが、サイトでは標高条件を選べず、旧URLの `model=elevation` も距離へ移行する。DEM由来の層がローカルに残ることと、標高絞り込みを実装・公開していることを混同しない。

国土地理院の申請はエラーのため中断し、入力・添付の控えをGit対象外へ保存した。申請送信・承認取得・一般配信は行っていない。コード公開と解析データ公開は別に管理する。

## 分割配信（2026-10-08）

`pack-spatial-delivery.mjs` は計算済みの値を変えず、集計と地域索引をgzip化し、広域図を県ごとに分割する。`delivery-manifest.json` を最後に更新する。元manifestのSHA-256と全配信ファイルのSHA-256、圧縮・展開サイズを検証する。起動時は集計・索引のみ、地図の広域データは対象県、詳細は表示範囲を取得する。広域キャッシュは展開前JSONのサイズ換算で48 MB、詳細は8タイルまで（JavaScriptの実ヒープ量ではない）。中断された読込はキャッシュへ入れず、古い操作結果で地図を更新しない。

分割前後のsummary、地域索引、2,724広域行・2,670地域別広域行は `check-delivery.mjs` で完全一致を検証する。元データの再計算・更新後には配信パックも作り直す。

## 土地被覆の個別選択（2026-10-08）

生息環境から得られる土地被覆をボタンでオン・オフできる。`excludeCover=6.7.9` のように、オフにした分類番号をURLに保持する。1～15の有効な分類番号のみを受理し、既定値は除外なし。検索対象の種や登録環境そのものは削除しない。除外は種どうしで共通とし、比較・CSV・GeoJSONへ同じ設定を適用する。画面上部にも変更した分類を表示し、どの種からでも全解除できる。

対象画素は、元の生息環境のAND/OR条件を満たし、かつ除外されていない土地被覆に属する画素とする。距離・植生条件と着色割合の分母は変更しない。すべてオフにすると `no_landcover`（土地被覆未選択）となり、面積ゼロ・未評価・環境未選択と区別する。CSVは使用・除外分類名、GeoJSONは `excluded_landcover_classes` と適用後の環境条件を保持する。元の研究データやルールは書き換えない。
