# 標高機能の申請・承認後の公開

2026-10-18更新。実装・全国データ・申請資料・画面確認・回帰テスト・配信設定の準備は完了。申請送信は利用者の指示で後日とし、実承認が届くまではローカル確認用に留める。公開中のサイトは標高が必要な環境の計算保留を維持する。

## 利用者の残る手続

申請を行い、承認が届いたらこのチャットへ知らせる。こちらで公式の承認書・申請記録から承認番号、対象URL、対象出力、指定表示を照合する。対象はWeb地図だけでなく `web_map`・`spatial_json`・`csv`・`geojson`・`presentation_figures` の5種類。実際の承認が準備した用途を覆うことを確認してから、承認記録の作成、表示への反映、最終検査、公開を行う。未承認・範囲不足・版の不一致では処理を止める。

## 準備した仕様

- 平地側の上限と山地側の下限を100m刻みで変更する。初期値は200m・800m。上限は下限より小さくし、100mから3000mまでの有効な基準だけを受理する。
- 原DEMを100m刻みで集計し、3000m以上と欠損をそれぞれ別区分にする。高さの限定が必要な環境では標高欠損を候補から除く。
- 平地・低山地・山地という文献の記述を、選択した標高範囲で近似する。地形分類や地域の植生帯を確定するものではない。距離・土地被覆・植生・地域条件も共通で適用する。
- 選んだ基準をURL、比較、CSV、GeoJSONへ保持する。閾値を変えた計算結果を混同しない。
- 海岸線・河川距離は今回の標高承認で解放しない。108環境を計算、19環境は海岸線・河川等の計算・配布を保留、51環境はその他の未評価。全178名称を検索できる。

## 画面の改善

検索欄を上へ移し、「地域・環境の条件」は現在値を示して折りたたむ。スマホでは検索結果を畳み、入力すると開き、種を選ぶと結果へ進む。検索0件時には入力した語を残して環境条件だけを解除できる。選択中の種も明記する。

環境選択パネルは画面内に収め、項目には短い概要を表示する。詳細条件と近似の限界は各項目の補足に残す。補足だけを閉じて選択を続けられる。比較表の土地被覆内訳は項目ごとに開閉する。

背景なしの地図にはローカル描画の地方名を加える。背景タイルは利用者が選ぶまで取得しない。重複していた範囲移動ボタンを整理し、CSVボタンの形式を明記する。GeoJSONには保存範囲の経緯度と、表示範囲を保って地図へ戻るボタンを設ける。
