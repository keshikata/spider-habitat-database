## 計算・配布を保留する素材

| 素材 | 判断と現在の扱い |
| --- | --- |
| 海岸線 C23・2006年 | [公式ページ](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-C23.html)が指定する[旧国土情報利用約款](https://nlftp.mlit.go.jp/ksj/other/agreement_02.html)第1・3条を確認。非商用の空間演算結果と、GIS・Excel等のデータベースの配布は区別されている。このアプリの条件別集計JSON・CSV・GeoJSONが出典表示だけで配布できるとは確認できず、距離データを配信・計算・保存から除外する。 |
| 河川 W05・2006～2009年 | [公式ページ](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-W05.html)の非商用・旧利用約款を確認。海岸線と同じ理由で距離データを除外する。 |
| 国土地理院DEM | [測量成果の利用手続](https://www.gsi.go.jp/LAW/2930-index.html)を確認。標高の絞り込みとDEM由来の数値データを初版へ含めない。既存申請は未送信・承認未取得。一般的な非商用利用だけを理由に手続不要と断定しない。 |

海岸線・河川の距離条件を必要とする19環境は「配布条件の確認待ち」。元から別の理由でも未評価の4環境を含む。環境名での種検索と条件の説明は残し、地図・候補面積には加算しない。単なる草地・森林や汎用の水域距離へ置換しない。現在は108環境を計算、19環境を配布条件の確認待ち、51環境をその他の未評価として扱う。

ブラウザーへ静的集計を渡すこと自体が第三者への配布に当たるため、保存ボタンだけを隠す対応にはしない。公開専用データは標高・海岸線距離・河川距離の軸を合算して取り除く。研究用の原本と解析コードは別に保持する。これらの保留機能を含めない初版の公開に、保留中の許諾回答を待つ必要はない。

## 発表資料の図版

元のPPTXと従来の画像は保持し、Web用コピーのみを編集した。アイコン類は所有者が自己作成・フリー素材と確認したため、削除せず維持する。20ページの資料自体、参考文献、メールアドレス、ResearchGateプロフィールは残す。発表者氏名はWeb用コピーから外し、引用文献の著者名は出典として残す。

引用については、[国立環境研究所の方針](https://www.nies.go.jp/site-policy/index.html)が著作権法上の引用を除外し出所明示を求めること、[文化庁の著作権解説](https://www.bunka.go.jp/seisaku/chosakuken/seidokaisetsu/pdf/94388701_01.pdf)が示す公表済み・引用の必要性・明瞭区分・主従関係・出所明示を踏まえた掲載構成にしている。単なる装飾や「出典さえ書けば自由な転載」としては扱わない。引用図の再配布権を本サイトが付与するものではない。

国土地理院の[手続ナビ](https://service.gsi.go.jp/onestop/navi/nav5-2/)には、学会発表や一般公開される論文が申請不要となる例がある。DEMを計算に用いて別の主題図を作る行為は、単純な複製ではなく[「使用」の事例](https://www.gsi.go.jp/LAW/2930-sample.html)に近い。一方、申請要否は利用形態で別に判断する。[Webへの挿入図](https://service.gsi.go.jp/onestop/navi/nav5-3/)にも申請不要の例がある。今回の6・9～12ページの実図には緯度経度の目盛があり、地図コンテンツを主とする本サイト内で配信するため、この掲載形態への適用は未確定として保留した。発表での使用自体に承認が必要だったという判断ではない。

許諾申請・問い合わせの送信は行っていない。利用条件を確認できた後、該当する機能・図版だけを追加できる。
